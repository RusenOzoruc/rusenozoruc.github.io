# Previewing modernization-v1 safely

This branch has a browser preview setup using GitHub Codespaces.

## Open the preview

1. On GitHub, switch the repository branch to `modernization-v1`.
2. Click the green **Code** button.
3. Open the **Codespaces** tab.
4. Click **Create codespace on modernization-v1**.
5. Wait for the Codespace to open. The website preview should open automatically in a new browser tab.

If it does not open automatically:

1. In the Codespace, open the **Ports** tab at the bottom.
2. Find port **8000** labelled **Website Preview**.
3. Click the globe/open-in-browser icon.

## Important

- This previews only the `modernization-v1` branch.
- It does not merge anything.
- It does not modify `main`.
- It does not change the live website.
- Closing or deleting the Codespace does not delete the branch.

The preview server starts automatically each time the Codespace starts.
